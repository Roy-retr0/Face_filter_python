
# Python Face Filter 

Un proyecto personal que recrea un filtro facial desde cero con python, utilizando algunas librerias como opencv y mediapipe. 


## ¿Qué Aprendí?

En este proyecto aprendí a estrucutar mis proyectos, desde como llamar a las funciones, hasta trabajar de forma organizada con diferentes archivos, al igual que trabajar con librerias "complejas"

Por último, me di cuenta de como funcionan los filtros faciales que son de uso cotidiano en diferentes aplicaciones de redes sociales, nunca me imagine la complejidad detras de in producto tan cotidiano 
## Dependencies
- python
- pip
- opencv
- mediapipe
## Deployment

Como recomendación personal, es preferible crear un entorno virtual antes de empezar a trabajar, de esta forma, pueden hacer cambios sin afectar su entorno de python global.

### Primero ejecutemos el siguiente comando
Creamos un entorno virtual

```bash
  python3 -m venv .venv 
```
### Activamos el entorno virtual

```bash
  source .venv/bin/activate
```
### Comprobar Entorno Activo
Este comando nos ayudará a conocer si estamos dentro de un  entorno virtual
```bash
 which python
```

### Ejemplo de entorno virtual
Entorno Virtual Activo

```bash
Face_Filter/.venv/bin/python
```
Si la ruta marcada contiene ".venv/bin/python" significa que el entorno está activo


### Clonando el repositorio
Una vez activado el entorno, procede a clonar el repositorio de github
```bash
 git clone "link del repositorio"
```

### Instalamos las dependencias
```bash
pip install -r requirements
```




*Instrucciones adicionales:* 

Para dejar de ejecutar el programa, presionar la letra   "q"
